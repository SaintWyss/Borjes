    Reemplazar el stub de scan_folder con la implementación completa. El cuerpo de la función debe:

    1. Declarar `const EXCLUDED: &[&str] = &["node_modules", ".git", ".cache", "Steam", "target", "__pycache__", ".Trash"];`.

    2. Construir el walker con `ignore::WalkBuilder::new(root).follow_links(false).filter_entry(|e| { let name = e.file_name().to_str().unwrap_or(""); !EXCLUDED.contains(&name) }).build()`. El filtro devuelve false (excluye) cuando el nombre del entry está en EXCLUDED; esto poda el subtree completo de ese directorio.

    3. Agregar al top del archivo: `use ignore::WalkBuilder; use std::{collections::{HashMap, HashSet}, path::PathBuf, os::unix::fs::MetadataExt};`.

    4. Inicializar antes del loop: `let mut nodes: Vec&lt;FolderNode&gt; = Vec::new()`, `let mut path_to_id: HashMap&lt;PathBuf, usize&gt; = HashMap::new()`, `let mut visited_inodes: HashSet&lt;u64&gt; = HashSet::new()`.

    5. Iterar el walker. Para cada entry Ok(e): calcular `is_dir = e.file_type().map(|t| t.is_dir()).unwrap_or(false)` y `is_symlink = e.path_is_symlink()`. Procesar el entry si `is_dir || is_symlink`. Para symlinks: obtener metadata del target con `std::fs::metadata(e.path())` (sigue el link); si el target no es un directorio, skip. Llamar `std::fs::canonicalize(e.path())` — si falla (link roto), skip con continue. Obtener inode con `std::fs::symlink_metadata(e.path()).map(|m| m.ino())` del propio symlink (no del target) para detectar duplicados; si el inode ya está en visited_inodes, skip; sino insertarlo.

    6. Para cada entry procesado: `let id = nodes.len()`, `let depth = e.depth()`, `let name = e.file_name().to_str().unwrap_or("").to_string()`, `let path = e.path().to_path_buf()`, `let parent_id = path.parent().and_then(|p| path_to_id.get(p)).copied()`. Insertar `path_to_id.insert(path.clone(), id)`. Construir FolderNode con root_group=0 (provisional), child_count=0 (provisional). Push a nodes.

    7. PRIMER POST-PROCESO — root_group: iterar nodes, para depth==1 setear `node.root_group = node.id`. Para depth&gt;1, subir por parent_id hasta depth==1 usando el vec indexado. Implementar via HashMap&lt;usize, usize&gt; (id → root_group) que se llena de depth 1 hacia abajo: iterar nodes en orden de id (ya están en BFS/DFS order del walker), para cada nodo buscar su parent_id en el mapa, copiar su root_group.

    8. SEGUNDO POST-PROCESO — child_count: declarar `let mut counts: HashMap&lt;usize, usize&gt; = HashMap::new()`. Para cada node, si `parent_id = Some(pid)`, incrementar `counts[pid]`. Luego iterar nodes y asignar `node.child_count = *counts.get(&node.id).unwrap_or(&0)`.

    9. Devolver nodes.

    Nota sobre el nodo raíz: el walker entrega `depth=0` para el propio `root` path. Incluirlo como nodo id=0, depth=0, parent_id=None, root_group=0 (el nodo raíz es su propio grupo a efectos de código; se distingue en render por depth==0).
  </action>
