<objective>
Satisfy DESK-02: the graph is revealed by Meta+D / minimizing windows and coexists with the Plasma
wallpaper. This is mostly an OS-config + verification phase, not app code — EWMH exempts desktop
windows from "show desktop", so reveal needs no code (the Wave-0 WinitSettings Continuous already

fight. Per the project's standing rules, a Plasma config change is per-machine, reversible, needs the
user's OK, and must be registered in sync-control — so it is gated behind a human-verify checkpoint,
never scripted autonomously.

recording the required per-machine setup; the change registered in sync-control.
