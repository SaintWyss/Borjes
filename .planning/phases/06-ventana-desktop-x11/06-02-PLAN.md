    Three edits. Codex writes; Claude builds.

    1. src/desktop.rs — DELETE all x11rb / raw-window-handle code. Replace with the overlay toggle:
       - A module-level `static TOGGLE_REQUESTED: AtomicBool = AtomicBool::new(false)`.
       - `extern "C" fn handle_sigusr1(_: i32)` that does `TOGGLE_REQUESTED.store(true, Ordering::SeqCst)`.
         Signal handler must be async-signal-safe: ONLY the atomic store, nothing else.
       - A Startup system `install_signal_handler` that registers the handler via
         `unsafe { libc::signal(libc::SIGUSR1, handle_sigusr1 as libc::sighandler_t); }` — wrap the single
         unsafe call, document why it's sound (only touches an AtomicBool). NO `.unwrap()/.expect()`.
       - An Update system `toggle_overlay_visibility(mut windows: Query<&mut Window, With<PrimaryWindow>>,
         keys: Res<ButtonInput<KeyCode>>)`:
           * if `TOGGLE_REQUESTED.swap(false, Ordering::SeqCst)` → flip `window.visible`. When turning visible,
             also set `window.focused = true` so egui search + camera get input.
           * if `keys.just_pressed(KeyCode::Escape)` AND window.visible → set `window.visible = false`.
       - Keep `pub` on the two systems. Remove `DesktopModeApplied` and `apply_desktop_window_type`.

    2. src/main.rs:
       - Window: `decorations: false`, `mode: WindowMode::BorderlessFullscreen(MonitorSelection::Current)`,
         `visible: false` (START HIDDEN), `window_level: bevy::window::WindowLevel::AlwaysOnTop`. Drop `focused:false`.
       - WinitSettings: use Reactive modes (NOT Continuous) — goal = NO continuous full-framerate redraw of a
         static graph. Match bevy 0.19's `UpdateMode` field shape (the compiler is ground truth for the exact
         `Reactive { wait, .. }` / `ReactiveLowPower { .. }` fields).
       - Remove `insert_resource(DesktopModeApplied::default())` and the `apply_desktop_window_type` entry +
         its `use` import. Add `install_signal_handler` to Startup and `toggle_overlay_visibility` to the
         Update chain (replacing the removed system). Update `use crate::desktop::{...}`.

    3. Cargo.toml — REMOVE the `x11rb = "0.13"` and `raw-window-handle = "0.6"` direct deps added in 06-01
       (overlay needs neither; they stay as transitive deps of winit). Do not touch Cargo.lock versions.

    Match existing style. No fenced code in this plan.
