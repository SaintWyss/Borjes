<objective>
Close the persistence-to-pixels loop: pins survive collapse, rescan, AND restart. Plan 02 paints a node gold the moment you pin it, but on a fresh launch or a Reescanear the nodes are spawned anew with their cluster material and the gold is gone. `apply_pins` runs every frame over folder nodes that are NOT yet `Pinned`, and for any whose path is in the disk-loaded `PinStore` it re-applies the gold mark — so the same system covers startup load (PIN-02) and rescan re-mark (PIN-03 "always visible"). Then a human confirms the whole flow on the live overlay, because egui + 3D picking cannot be script-driven.

Purpose: Deliver the "siempre visibles / sobreviven reescaneo" guarantee (PIN-02/PIN-03) and get the only verification that matters for this UX — a person pinning a node, rescanning, restarting, and seeing it stay gold.
Output: the apply_pins system (interaction.rs) + its Update registration (main.rs) + a passed human-verify checkpoint.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| disk-loaded PinStore → ECS visual state | apply_pins maps stored paths onto live entities; a stale path simply matches no node (no-op) |
| reroot/restart → ECS state | nodes are despawned/respawned; pinned state is re-derived from PinStore, never from surviving entities |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-07 | Information Disclosure / stale state | a pinned path that no longer exists after a reroot | accept | apply_pins only paints nodes present in the current GraphData; a missing path matches nothing and is harmless (the pin remains stored, re-appears if that root is scanned again) |
| T-08-08 | Denial of Service | apply_pins scanning every node every frame | mitigate | The query is filtered `Without<Pinned>`; once painted a node drops out, so steady-state cost is ~zero; per-frame work is bounded by unpinned-node count × a HashSet lookup |
| T-08-SC | Tampering | npm/pip/cargo installs | accept | N/A — zero new packages this phase |
</threat_model>
