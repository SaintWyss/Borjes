<objective>
Stand up the v3 drill-down view: replace the whole-galaxy render with a one-level hub-and-spoke renderer driven by the F10 FolderTree + radial_layout, under a fixed orthographic 2.5D camera. Left-click descends one level, Backspace/Esc ascends. This is the smallest shippable drill-down: STATIC placement (no animated transitions yet — instant level swap), no labels yet (F12), no glow (v4), pins/search rewire deferred (F13). The v2 galaxy systems (FR layout, global spawn, edges, burst/pin click) are unregistered but their code stays in the tree.

Output: src/drill.rs (NavState + level render + descend/ascend) + main.rs wiring (ortho camera, drill systems in, galaxy systems out).
</objective>

<execution_context>
Cross-AI: Codex writes src/drill.rs + the main.rs rewiring; Claude verifies (cargo build --release / clippy -D warnings / fmt --check + grep gates) and commits. Build/run is --release only. No new crates — bevy + std + the existing nav/scan modules. autonomous:false — ends in a human checkpoint because the visual drill-down can't be script-driven.
</execution_context>
