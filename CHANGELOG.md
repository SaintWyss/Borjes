# Changelog

## 1.0.0

- Arquitectura zero-idle mediante self-pipe y wake-up de winit.
- Render adaptativo durante interacción y reposo reactivo.
- Migración automática de configuración desde `datatree-rs`.
- Configuración unificada bajo `borjes`.
- Editor integrado de raíz y lentes temáticas.
- Peso visual basado en estructura y frecencia.
- Orden estable de archivos antes del límite de render.
- Assets portables fuera del repositorio fuente.
- Instalador, desinstalador, launcher y servicio systemd de usuario.
- CI con formato, Clippy, tests, release y RustSec.
